# Breinhap

Android study companion for Flemish students in 3de middelbaar, designed to work well for students with ADHD and AuDHD. Learning in small bites: 2 to 6 minute missions, always the same four steps, no time pressure.

- `apps/mobile`: the Expo Android app
- `apps/site`: the landing page, `breinhap.asafarim.site`
- `packages/content`: the learning-object format and sample content

```bash
pnpm install
pnpm test
pnpm mobile   # app
pnpm site     # landing page on http://localhost:4300
```

The product plan lives in the private docs repository: `asafarim-docs:ventures/breinhap/`. See `CLAUDE.md` for the rules.
